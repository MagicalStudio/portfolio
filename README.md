# Juan Guevara — Creative Portfolio

Personal portfolio showcasing professional work across video editing, motion graphics, graphic design, and web design.

## Tech Stack

- **Next.js 16** with App Router and TypeScript
- **Framer Motion** for animations
- **GSAP** for scroll-driven effects
- **React Three Fiber** for 3D elements

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Project Structure

```
src/
  app/          # Next.js app router pages
  components/   # Reusable UI components
  context/      # React context (language, theme)
public/
  ai-content/         # AI-enhanced video content
  motion-graphics/    # Animated flyer videos
  photo-manipulation/ # Photo editing work
  reels-covers/       # Social media reel covers
  social-media/       # Social media design assets
  tools/              # Software tool logos
  ui-ux/              # UI/UX web design screenshots
  youtube-longform/   # Long-form YouTube video content
  youtube-thumbnails/ # YouTube thumbnail designs
```

## Build

```bash
npm run build
npm run start
```
